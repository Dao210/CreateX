# Resident assets

Geometry, skeletons and animation clips by [Quaternius](https://quaternius.com), CC0 1.0 Universal. Downloaded from the author's free Standard distributions on 2026-11-06:

- [Universal Base Characters](https://quaternius.itch.io/universal-base-characters): Superhero Male/Female base geometry and Buzzed/SimpleParted hairstyles. Original license: LICENSE-characters.txt.
- [Universal Animation Library](https://quaternius.itch.io/universal-animation-library): Idle, Talking, Walk, Fixing, PickUp, Interact and Sitting clips. Original license: LICENSE-animations.txt.

GLBs embed the original geometry and rig; unused textures and animation clips were removed for delivery. Resident clothing colors are applied by the renderer. No runtime CDN requests or model credentials are used. Town architecture, terrain and material textures are authored in the adjacent TypeScript modules.

Terrain uses [Grass004 from ambientCG](https://ambientcg.com/a/Grass004), CC0 1.0 Universal ([license](https://docs.ambientcg.com/license/)). The original 1K color and OpenGL normal maps are encoded as WebP for delivery. The road layout is authored from the authoritative town navigation coordinates; no external assets are fetched at runtime.
