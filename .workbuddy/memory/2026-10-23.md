# 2026-10-23 项目分析与优化建议

## 结论
对 createx（Auro：人与 Agent 协作任务管理平台，~129 万行）做了全仓扫描，输出优化建议。最大发现：**仓库无 .git 元数据**（.gitignore/.github/.gitattributes 齐全但 git 丢失），为 P0 风险。

## 关键数据
- 规模：server(Go) 78.9 万行/1999 文件；packages/views 30.5 万行/1211 文件；core 8.8 万；web 3 万；desktop 2.5 万；mobile 3.5 万
- 测试：788 TS 测试文件 + 1172 Go 测试文件 + 36 e2e spec；handler 包 443 文件中 313 是测试
- migrations 实际在 server/migrations（1180 个 .sql），internal/migrations 只放迁移测试

## 确认的问题
1. P0：无 .git → 无回滚、turbo 缓存 hash 源退化（turbo.json 注释依赖 git-tracked 语义）
2. P1：packages/views/search/search-store.ts 用 zustand create() 定义 store，违反 AGENTS.md「views 禁止定义 store」边界（本仓约定 store 住 core/<domain>/stores/）
3. P1：God object——daemon.go 10637 行/230 func、service/task.go 8095 行、handler/daemon.go 6110 行、issue-detail.tsx 3972 行、core/api/client.ts 5236 行
4. P1：4 个 *backfill 包+cmd 入口共 8 处，一次性数据修补任务常驻 internal/
5. P2：packages/plugin-sdk 未列入 AGENTS.md 包职责表；packages/ui 零单测；根 .env 176 行/99 键疑有死键；docs/ 文档重叠+日期稿散落
