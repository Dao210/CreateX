## 技巧：`go build -overlay` 做零落盘验证

沙箱会拒绝 `cp -R` 大目录（file-read-data policy）。改用 Go 原生 overlay：
```bash
python3 -c "...读源文件改写后写到 /tmp/xxx.patched.go..."   # 生成替换文件
echo '{"Replace":{"<abs源路径>":"/tmp/xxx.patched.go"}}' > /tmp/overlay.json
cd server && go build -overlay=/tmp/overlay.json ./...
```
工作区零改动，可安全验证「假设修复后会不会通过」。
