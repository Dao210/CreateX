## REACH M0 实现（server/internal/reach + server/cmd/reach）

- 已落地：类型/校验/派生、参数化几何编译、确定性 beat 引擎、双语播报、文件持久化、幂等提交、orders、HTTP 全端点、独立二进制。PRD 增补 §15「M0 落地状态」。
- 核心实现决策（后续改动必须守住）：
  - 全部结算用 **int64 定点**（千分位），不用 float，保证跨机器 replay 一致；随机只用 `mix64(seed ^ beat ^ fnv(key))`，不用 math/rand。
  - `Digest()` 每 beat 用 FNV+mix 累加实体状态，重放可直接比对；TestReplayIsDeterministic 锁住。
  - 实体按 `bucketSize = 384*Milli` 网格分桶查 3×3，覆盖最大 sense(340)。2000 实体 **2.7ms/beat**（预算 200ms）。
  - 校验返回**全部**字段错误（422 + `fields[]`），不是遇到第一个就返回 —— 这是 agent「一次修正通过」的前提。
  - `entity-1.json` 由校验器的闭集 map 生成，`TestEntitySchemaMatchesValidator` 防漂移；闭集改动只改 spec.go 一处。
  - 去重按 spec 指纹：同 spec 不同 idempotency key 返回原实体 + `duplicate` note，不重复入场。
- 实测踩到的两个契约问题（已修，注意别再犯）：`Derived` 无 json tag 导致回执输出 PascalCase；空世界 `Chronicle` 用 `append(nil,...)` 序列化成 `null`，前端 len() 直接炸 —— 空集合必须返回 `[]`。
- 端到端验证：well-known → schema → submit（201 + cookie）→ 幂等重放同 id → 422 逐字段 → order 200/匿名 403 → 重启后 beat 延续（23→24）。持久化在 `/tmp/reach-dev2/world.json`。
- 本地起服务：`cd server && REACH_DATA_DIR=.reach REACH_SEED=42 REACH_BEAT_SECONDS=1 go run ./cmd/reach`（默认端口 127.0.0.1:18107）。curl 记得 `--noproxy '*'`。
- 未做：赛季冻结/名人堂、voice 的 LLM 审核、SSE、全部前端页面（`/world`、`/world/build`、`/developers/reach`）、Makefile `C=reach` 集成。

## REACH 营销首页改版（apps/web，第 2 轮精修）

- 结构定稿：`LandingHeader(dark)` → 控制条（`REACH — 世界 / 赛季` + `● LIVE|PREVIEW` 计数）→ 主张 h1 + sub + CTA → `世界窗口 2:1 + 播报侧栏`。**主张放在世界之上**是刻意的：900px 视口下「主张+副题+CTA+整块世界」能同时进首屏，且窗口能保持接近 2:1（世界网格 2048×1024，窗口越扁 cover-fit 裁得越狠，之前 3.7:1 只看得见中间一条）。
- 世界窗口高度不写死 vh，用 `lg:h-[clamp(320px,calc(100vh_-_440px),520px)]`：440 是「header+控制条+标题块」的实测固定开销，这样 800/900/1000 三种视口下窗口底边都稳定落在折线以上 30~40px。
- **坑**：把高度写在带 `pb-*` 的 grid 上会被内边距吃掉（450 的 grid 只剩 418 给孩子），表现为「明明设了 450 却算出 416」。要么把 padding 挪到父容器，要么把高度写在子元素上。
- **坑**：侧栏是 grid item，内容超过窗口时会**把整行撑高**（英文播报每条 2 行，9 条 519 > 448），导致画布和侧栏底边不齐。解法是高度定义在 grid 容器上 + 子项 `h-full` + 侧栏 `min-h-0 overflow-hidden lg:h-full`。
- 预览态不再显示空「—」：时钟直接渲染 fixture 的 beat/存活/残骸（另外用 PREVIEW 徽标标注 demo），规则三列改成**规则常量**（60 秒 / 100 点 / 30%，字典新增 `items[].f`），不依赖实时数据。
- 播报 fixture 必须按**时间正序**写（引擎是 append 语义，前端 `slice(-11).reverse()` 取最新在前）；之前写成倒序，页面就会把最老的排最上面。
- 世界画布可读性：`base = max(8.6, 19*scale)` + 米白核心 `max(1.3, base*0.17)` + 深色描边；三带加罗马数字 I/II/III 与 0.10 的虚缝；加 vignette 把视线收到中间；补给/残骸放大到 `max(3.5, 7~7.5*scale)`。预览 fixture 380 实体、9 个聚落（聚落内散布 260×190）。
- 文案：`text-balance` 用在中文副题上，避免出现只剩「一次。」三个字的孤行。footer 用 `LandingFooter tagline={copy.closing.footerNote}` 覆盖掉「人类+智能体的项目管理」那句，四语均已补 `world.closing.footerNote`。
- 验收：`tsc --noEmit` / `eslint features/reach features/landing` 全绿；`vitest run features/landing` 41 passed。
- 截图工具链仍是 `/tmp/reach-shot.mjs`（一次启动完成「设 Accept-Language → 量首屏 → 滚内层 `.landing-light` 分段截图」，`W`/`H` 走环境变量）。**必须用 localhost，不能用 127.0.0.1**。
- 待办（未做）：`/api/reach` 还没接 Next rewrite，本地与服务默认都走 PREVIEW（同源代理由部署侧负责）；`/world`、`/world/build`、`/developers/reach`、赛季冻结与名人堂仍未开工。

## 品牌替换：新 logo / favicon，去掉 GitHub 入口与巨型页脚字标
