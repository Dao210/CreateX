# DEAL 技术架构审阅

审阅依据：[PRD](deal-prd.md)、[架构](deal-architecture.md)、仓库 AGENTS.md 与现有 LLM/UI 契约。

## 开工前发现与修订

| 检查项 | 发现 | 执行方案 |
| --- | --- | --- |
| 产品隔离 | Auro Next 根布局会初始化认证/工作区基础设施 | 独立 apps/deal，不复用产品壳和账号体系 |
| 游戏裁决 | 自由对白可绕过弱语义检查泄露秘密或许诺放行 | 首版 AI 选择规则授权的对白，结果与动作始终由引擎确认 |
| 模型缺失 | 自动关键词替代会掩盖 AI 实际不可用 | 默认 AI，缺配置明确报状态；规则试玩仅显式开启 |
| 存储 | 内存会话无法重启恢复，独立数据库会扩大范围 | 单实例原子文件快照，进程锁；后续多实例另行迁移 |
| 重试 | 保存状态后回复丢失可能重复扣时/交钱 | 持久化 request_id 和原输入指纹，重试查收据优先于版本校验 |
| 资源 | $3,000 无法解释付款/逃亡结局 | 四类首版结局；合同应收款与结余佣金形成真实可达链 |
| 时间 | 真实倒计时会惩罚网络和模型速度 | 8 分钟剧情时间，每次推进 20 秒 |
| 知识 | 完整秘密 Prompt 会给模型不必要的信息 | 理解模型只收公开视图，表演只收授权台词 |
| 假陈述 | 同意未来协议不等于资金已到账 | 声明、协议、付款事件分别处理 |
| 现有规约 | .git、apps/docs 约定文件缺失 | 不初始化/提交 Git；使用已给定 AGENTS 规则与独立产品中文文案 |

审阅结论：按修订架构开发单实例本地 MVP。没有外部账号/agent CLI 依赖；真实模型质量和公开托管仍需独立验收。

## 开发后审阅

### 修复的实现问题

| 项目 | 发现 | 修复与证据 |
| --- | --- | --- |
| 开发同源代理 | Vite 默认改写 Host，开局被 Origin 校验拒绝 | 显式 `changeOrigin: false`，保留同源检查；浏览器可开局 |
| 协议确认 | 首次提议立即进入结局，缺少接受动作 | 先生成待确认条款，再接受；替换条款撤销旧提案；引擎回归与三条成功路线通过 |
| 重开弹窗 | 同一 Dialog 在页头与结局同时挂载，产生两个弹窗 | 结局只保留一个入口；浏览器验证取消、确认新局和旧局保留 |
| 初始信息 | 私人物品标识可能提前透露 Sofia | 初始名称和 ID 使用中性旧照片；查看后才揭示姓名；公开快照与模型输入检查通过 |
| 资金矛盾 | 泛泛解释可能清除冲突，来源不完整 | 限制范围澄清线索，保留冲突与解释回合；回归覆盖无效解释与有效澄清 |
| 复盘 | 搜查可能漏计动作、未来承诺没有单列 | 使用服务器实际耗时统计；未来资金单列且不抵债；测试通过 |
| 模型成本 | 物品动作没有必要再请求台词选择 | 物品与等待直接用授权对白；文字最多两次调用 |
| 部署身份 | HTTPS 代理需要 Secure cookie 与同源协议一致 | 显式 HTTPS 配置并检查协议和 Host；HTTP/HTTPS 回归通过 |
| 桌面布局 | 770px 房间最小高度使桌面与开口按钮超出常见视口 | 按视口调整角色与桌面；桌面与 390px 窄屏已视觉检查 |

### 审阅结论

首期本地 MVP 开发完成。Go 规则、API、文件存储、真实 SDK 的本地模拟服务、LLM 调用边界契约与竞态检查通过；前端类型、lint、单元测试、正式构建通过；Go 同源托管正式构建的六项浏览器流程通过。详见[交付记录](deal-delivery.md)。

公开 API 只序列化 PublicSession，所有权、心理、声明内部引用和规则阈值不会返回客户端；物品秘密在观察前不进入响应。引擎负责事实、收益、资金、机会、时间和结局。模型只能抽取受限意图，并从授权台词中选择，不能生成世界写入。

剩余验证边界：真实模型的语义正确率、提示注入语料回归、延迟与成本尚未测量；未开展陌生玩家测试、公开部署或语音接入。声明解析当前只覆盖资金命题，澄清采用有限范围线索，不能宣称开放领域推理能力。文件存储仅支持 macOS/Linux 单实例，验证了进程重启恢复，未做掉电/磁盘故障灾难恢复验证；500 局上限是本地资源约束，不能替代公开服务预算与限流。

当前没有待修复的本轮阻塞项。首版玩法和 AI 质量仍需依上述边界独立评价，不能用规则试玩通过代替。
