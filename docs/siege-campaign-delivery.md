# Doodle Siege：林地战役

`/siege/play/` 是新增的闯关页面；`/siege/` 保留武器工坊，并提供“林地闯关”入口。两页通过 Vite 多入口构建，由现有 Go 静态服务同源托管；闯关路由可以直接打开和刷新。

## 可玩的范围

- 8 张林地地图，每关 5–8 波，包括回形路、双入口与末关首领。
- 林地火炮、霜露炮、旋转刃、重锤、松果爆破炮，按关卡解锁；普通兵、疾跑兵、重甲兵、群怪、护旗手及半血召援军的首领。
- 阵位建造、金币、三级升级、出售返还总投入的 70%、集火与清障。障碍有生命、金币奖励，并开放原来被占用的阵位。
- 三星目标：通关、城堡无伤、障碍全清。通关开放下一关；结算能重试，失败显示实际漏怪的波次与路线。
- 暂停布阵、真正增加物理步进的二倍速、后台自动暂停、音量与静音、伤害和金币反馈。
- 预设直接开玩；工坊草稿及匿名会话已保存蓝图可导入。炮管长度 1.60–3.20 m、粗细 0.45–1.05 m，继续通过既有确定性几何与武器编译器计算性能。自由绘图中的刀刃、锤头和炮台保持原画；盾牌及混合近战类别需在工坊拆分后再部署。

部署冻结蓝图。之后的改装只影响新建武器，现有武器的形状、性能与实战统计保持不变。减速不叠加；首领减速和击退效果减半。旋转刃按目标设置接触间隔，可同时命中群体，并防止同一敌人被多个部件重复计伤。溅射只在真实炮弹命中后，对每个附近目标结算一次。

## 存档与运行边界

星级、当前关卡、音效、音量、倍率和待部署改装存在本地浏览器；这些数据没有上传或跨设备同步。蓝图库继续使用工坊的匿名 Cookie 与既有 API 所有权边界。

完成一波后保存金币、城堡生命、已清障碍、炮台位置与等级、部署蓝图和实战统计。刷新、离开战场或进入工坊，从最近波间断点继续，进行中的波次重新开始；恢复后需主动点开始。版本不适用或几何不合法的断点拒绝恢复，历史星级独立保留。存储失败会明确提示，本次战斗仍可继续。

战斗使用一个独立 Rapier 世界、固定 60Hz 步进、传感器近战和真实 CCD 炮弹。击退只回退合法路径进度，不删除活着的敌人。只有全部波次及首领援军出场、剩余敌人全部处理且城堡存活才胜利；城堡归零立即失败。

在场敌人上限 40、炮弹上限 96。敌人满额时延后出场，不丢弃波次；炮弹满额等待命中或清理，页面显示上限提示。效果列表最多 40 个，事件最多 2,000 条。玩家可主动导出本地战斗记录，包含结果、当前炮台蓝图与操作事件；超过事件额度时导出包含截断标记，不自动发送数据。

## 运行

```bash
pnpm --filter @auro/siege build
SIEGE_RECOGNITION_MODE=fixture make up C=siege
make status C=siege
```

开发页面：`http://127.0.0.1:13107/siege/play/`。同源正式构建：`http://127.0.0.1:18107/siege/play/`。`make down C=siege` 停止并保留数据；现有独立环境与数据目录不变。

默认预设和战斗不需要 AI。显式 fixture 仅用于既有工坊识别样例的回归；已保存蓝图库暂时不可读取时，仍可使用本地预设与草稿。
